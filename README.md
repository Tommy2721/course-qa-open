# 课问 · 课程知识问答与复习助手

> AIC 2026 算法主题赛（AI+开源）参赛作品
> **参赛方向**：（一）开源赋能的 AI 应用创新　|　**作品形态**：网页应用（本地部署，可在线演示）
>
> 面向大学生单门课程的开源大模型问答与复习工具：上传课件 → 提问 → 得到带出处页码的答案 → 系统记录薄弱知识点 → 生成复习清单。

## 这个项目解决什么问题

学生在复习时反复遇到同一个困境：课件有几百页，想问"这个公式在哪个前提条件下成立"，
但通用聊天机器人不知道你们课上讲了什么，会一本正经地编造答案。

本项目用**开源模型 + 开源向量库**在本地搭建课程知识库，特点是：

1. **答案带出处**：每句话标注 `[1][2]`，可定位到课件第几页
2. **不知道就说不知道**：两级拒答机制，不编造
3. **每句话都核验过、有问题就自动改（★ 核心创新）**：答案生成后自动拆成一条条结论，
   逐条回课件原文找支持句——找到的展示原文，找不到的先尝试**自动修订**
   （只改无依据的结论，改完复验，变好才采纳），改不掉的明确标记
   "课件未直接支持"。把"有引用"变成"引用真被原文支持"
4. **越用越懂你**：记录反复提问的知识点，识别薄弱环节，生成复习清单

## 检索是怎么做的（七层设计，每一层针对一类具体失败）

| 层 | 做法 | 针对的失败 |
|---|---|---|
| 1 | 向量 + BM25 双路召回，**RRF 按排名融合** | 向量不懂专有名词/编号，BM25 不懂同义表述；两路分数不同量纲，不能用加权相加 |
| 2 | **查询扩展**：用本地大模型把口语提问改写成多个专业检索式 | 学生问"学习率调太大会怎样"，课件写的是"震荡发散"——词面对不上时两路都会失手 |
| 3 | **交叉编码器重排** | 双塔检索精度有限，把"问题+段落"一起过网络更准 |
| 4 | **MMR 去冗余**（可选，默认关） | 章节内相邻块高度重叠时避免浪费上下文预算；实测在本语料上收益为负，见代码注释 |
| 5 | **小到大检索**：用小块检索（准），命中后扩成整章送模型（全） | 结论找到了，但它成立的前提在上一段 |
| 6 | 章节感知分块 | 固定长度硬切会把公式和它的前提条件切散 |
| 7 | **两级拒答**：分数阈值 + 答案级检测 | 单靠分数覆盖不了"检索到相关段落、但段落里没答案"的情况 |
| 8 | **答案逐句核验**：断言拆分 → 向量粗筛 → 重排精算 → 标记无依据结论 | 模型标注 [1] 不代表这句话真被原文支持；这是"可验证"的量化实现 |

这些层可以**通过开关逐层关掉**，所以能跑消融实验，用数据说明每一层各自带来多少提升
（`python -m src.eval --mode retrieve`）。

## 技术栈（全部开源，许可证可披露）

| 层 | 组件 | 许可证 |
|---|---|---|
| 大模型 | Qwen2.5-7B-Instruct（Ollama 本地部署） | Apache-2.0 |
| 向量模型 | BAAI/bge-m3 | MIT |
| 重排模型 | BAAI/bge-reranker-v2-m3 | Apache-2.0 |
| 向量库 | Chroma | Apache-2.0 |
| 关键词检索 | rank_bm25 | Apache-2.0 |
| 中文分词 | jieba | MIT |
| 文档解析 | pdfplumber / python-pptx / python-docx | MIT |
| 界面 | Streamlit | Apache-2.0 |
| 推理服务 | Ollama | MIT |

> ⚠️ **刻意避开 AGPL 组件**：PDF 解析没有使用 PyMuPDF（AGPL-3.0，有强传染性，
> 会导致整个项目被要求以 AGPL 开源），改用 MIT 许可的 pdfplumber。

## 快速开始

```bash
# 1. 创建虚拟环境
python -m venv .venv
source .venv/Scripts/activate      # Git Bash；PowerShell 用 .venv\Scripts\Activate.ps1

# 2. 安装依赖
python -m pip install -r requirements.txt

# 3. 安装并启动 Ollama（见「开发指导.md」），拉取模型
ollama pull qwen2.5:7b-instruct

# 4. 启动界面（推荐）：双击 启动界面.bat
#    在「课件管理」页签上传 PDF/PPT/Word，点「保存并重建索引」（后台执行）
#    然后在「向课程提问」页签即可问答

# 命令行方式（调试用）
python -m src.index                        # 建索引
python -m src.answer   "你的问题"           # 命令行问答
python -m src.eval --mode retrieve         # 检索消融实验
```

## 界面功能

- **向课程提问**：答案带 `[1]` 引用编号，出处条目可展开定位到课件该处原文；课件没有的内容明确拒答
- **学习分析**：从提问记录识别薄弱知识点，一键导出复习清单
- **检索调试**：各路召回分数全透明，可现场关闭某一层对比效果
- **课件管理**：界面直接上传/删除 PPT / Word / PDF，一键保存并后台重建索引
- **项目速览**：作品说明与任务分工
- **历史对话**：「➕ 新建对话」自动归档，侧边栏可恢复任意一次对话（持久化保存）

## 目录结构

```
course-qa/
├── app.py                  # Streamlit 界面
├── config.py               # 全部可调参数集中在这里
├── requirements.txt
├── src/
│   ├── parse.py            # 文档解析：PDF/PPT/DOCX → 带页码的文本
│   ├── chunk.py            # 分块（★ 自研点 1：章节感知分块）
│   ├── index.py            # 建索引：向量库 + BM25
│   ├── retrieve.py         # 混合检索（★ 自研点 2：RRF 融合 + 重排）
│   ├── answer.py           # 生成答案 + 引用溯源 + 拒答（★ 自研点 3）
│   ├── profile.py          # 学习分析：薄弱点识别（★ 自研点 4）
│   └── eval.py             # 评测脚本：Recall@5 / 拒答正确率
├── eval/
│   └── questions.example.jsonl   # 评测集格式示例
└── data/
    ├── raw/                # 放课件（不提交到 git）
    └── index/              # 索引持久化目录（不提交）
```

## 评测

```bash
python -m src.eval --mode retrieve    # 只跑检索指标（无需 LLM，快）
python -m src.eval --mode full        # 跑完整流程（含答案准确率，慢）
```
